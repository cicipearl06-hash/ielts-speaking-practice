# 雅思口语每日打卡 · 使用指南

## 文件说明

- `index.html` — 完整应用，直接双击用浏览器打开即可

---

## 快速开始

1. **双击 `index.html`** 用 Chrome / Edge 打开
2. **（可选）** 点击右下角 ⚙️，填入 Claude API Key 以获取 AI 评分

---

## 功能一览

### 左侧进度栏
- 完整展示所有 Part 1 话题 + Part 2 四大类别（共38道话题卡）
- **绿色圆点** = 已完成（含得分）
- **金色圆点** = 今日选中
- **灰点** = 还未做
- 点击任意话题可直接选为当日练习

### 每日练习流程
```
Part 1（4题 × N秒/题）
    ↓
Part 2（1道话题卡 · 准备1分钟 + 陈述2分钟）
    ↓
Part 3（3-4题 × N秒/题）
    ↓
📊 AI 评分报告 + 参考答案
```

### 计时规则（可在设置中调整）
| 模块 | 默认时长 |
|------|----------|
| Part 1 | 20 秒/题 |
| Part 2 | 准备1分钟 + 陈述2分钟 |
| Part 3 | 20 秒/题 |

### 数据永久保存
- 所有打卡记录、得分、进度保存在浏览器 localStorage
- 刷新不丢失，可查看历史报告
- 支持选题练习（点击左侧任意话题）

---

## 配置 API Key

1. 访问 https://console.anthropic.com/
2. 创建 API Key（格式：`sk-ant-...`）
3. 打开网页 → 右下角 ⚙️ → 粘贴 Key → 保存

> 不填 Key 也能用计时和录音功能，但无法获取 AI 评分。

---

## 浏览器要求

- **推荐 Chrome**（语音识别支持最完整）
- Safari / Edge 部分支持
- 语音功能需授权麦克风权限
